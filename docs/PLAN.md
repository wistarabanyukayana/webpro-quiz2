# Spending Tracker (Quiz 2)

Java/JSP version of our Laravel ETS project (github.com/TsarVib/webpro-ets), with the same features.

Team:
- Wistara Banyu Kayana: code
- Ito: testing

Stack: Java 21, Tomcat 11 (Servlet, JSP, JSTL), SQLite, Tailwind CSS, Docker.
